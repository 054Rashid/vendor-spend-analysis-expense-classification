I normalized inconsistent vendor names, mapped transactions to a vendor master, validated expense classifications, detected duplicates and spend anomalies, created an exception queue, and produced vendor/category/department/monthly spend analytics.

Production extensions: governed taxonomy, effective-dated vendor master, warehouse, dbt tests, orchestration, approval workflow, anomaly models and automated alerts.
